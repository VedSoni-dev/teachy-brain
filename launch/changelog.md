- Free MIT open-source macOS teaching companion (courses-first)
- Learn paths: First Win with AI, Use AI to Code, GitHub, YouTube basics
- Notch panel, screen pointing, push-to-talk, LessonPlayer coach loop

Right-click → Open (Gatekeeper). Grant Mic / Screen Recording / Accessibility. Run the Teachy proxy (`worker/`) with your OpenRouter key.
