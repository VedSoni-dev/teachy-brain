# 0012 — Own A&M with OpenClaw-grade AI fluency coaching

**Date:** 2026-07-29
**Status:** accepted
**Affects:** teachy-app desktop, teachy-web Academy, Aggie Innovators distribution

## The question

How does free, open-source Teachy become the default AI-fluency coach for Texas
A&M — not another ChatGPT wrapper students ignore?

## The decision

**Teachy is the OpenClaw of teaching AI fluency:** an always-on, screen-grounded
agent that grips a goal, remembers the learner, and walks Vedant's stack defaults
(Vapi / Vercel / Cursor / …) turn by turn — B2C free, MIT, one Electron shell.

Market capture is **distribution × reliability × taste**, in that order for A&M:

1. **Distribution** — Dean + Aggie Innovators (~500) install the same build in
   one sitting; Academy is the home / waitlist / newsletter later.
2. **Reliability** — Ask must work cold: key setup, Screen Recording, capture,
   stack lock, multi-step path, speak/point. No "demo only works with Vedant."
3. **Taste** — Opinionated pathways beat generic tutors; that's the wedge the
   Dean can endorse as *how Aggies learn to build*.

Newsletter push-open and full act-for-me (Accessibility) are phase-two. Do not
block the club rollout on them.

## Why

A&M does not need another curriculum PDF. They need a coach that sits next to
students while they ship. OSS + free removes procurement friction; the Dean
channel removes discovery friction. Product bar is agentic grip, not feature
count.

## What it costs us

- We will look narrow (Vedant stack) to people who want "any tool." That is fine
  for the wedge; overrides exist.
- Mac voice hold-to-talk and Windows parity must not diverge again — one React
  shell (0011).

## When to revisit

If Aggies bounce because the agent cannot act on screen, promote Accessibility /
click-for-me ahead of newsletter. If the Dean wants campus-wide before club
proof, ship a one-page install + 3-prompt demo script first — do not rebuild the
product.
