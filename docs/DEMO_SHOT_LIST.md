# 60-second demo — shot list

Film this on your Mac (QuickTime / Screen Recording). No music needed. Captions help.

## Setup before record

1. Clean desktop or one browser window
2. Teachy running, proxy up (`cd worker && npm run local`)
3. Permissions already granted (skip Settings rabbit holes on camera)
4. Start recording at 1080p, hide your menubar extras if messy

## Timeline (~60s)

| Sec | Shot |
|-----|------|
| 0–5 | Cold open: title card or notch “Teachy” + text on screen: “Free 1:1 tutor on your real Mac” |
| 5–15 | Expand notch → Learn → start **First Win with AI** |
| 15–35 | Coach speaks / points at something real (browser or AI chat). You follow once. Show the chalk/cursor point. |
| 35–50 | Goal completes or “I did it” moment — quick celebration |
| 50–60 | End card: `github.com/VedSoni-dev/teachy` + `vedsoni-dev.github.io/teachy` + “Free · MIT · macOS” |
